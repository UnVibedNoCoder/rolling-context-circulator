# Proposed 0.3.0-beta.1

Proposal date: 2026-10-05; final public sanitisation: 2026-10-06. This is a packaging proposal, not an authoritative upstream version bump or tag. Existing source version strings (including generated shim `0.2.0` and relay `0.1`) are retained to preserve runtime identity. `RELEASE_METADATA.json` records the candidate and source fingerprint separately.

This candidate packages the current deterministic context circulator, immutable local RAW/source versions, source-linked Librarian compaction, READY/admission tracking, bounded recall and current-file snapshots, task reconciliation, Loop Guard, numeric Generation Governor, and owned-child relay lifecycle fixes. No runtime code/configuration tuning was performed for packaging.

Runtime Python modules and launch/install/uninstall/verify tooling match the production bytes. Release-only changes include MIT licensing, corrected and anonymised public findings, generic synthetic loop/continuity regression data, three replay-input and two telemetry-reader regressions, a portable source-root test assertion and a synchronized integration-test telemetry reader, sanitized historical campaign paths/outputs, and explicit archive/session arguments for retained replay helpers. Four historical helpers are excluded: two reasoning inspectors, the fixed-process cleanup and an archive-specific continuity replay. Example configs and refreshed portable manifest/inventory/evidence are included. SOURCE_COMPARISON.json lists each difference.

Historical acceptance: two jobs admitted once, a 35,178 -> 26,689 content-token reduction, continued execution after compaction, privacy pass and provider stability. Full historical verification: 252 tests and seven checks. Fresh packaged verification is recorded in PACKAGE_AUDIT.

In an independently audited downstream coding workload, Rolling Context successfully preserved continuity while the underlying agent still produced incorrect technical work and overstated its own verification. Context continuity therefore does not guarantee output correctness. Preserved history does not prove conclusions are correct. Successful compaction does not validate generated code. Passing Rolling Context tests does not validate downstream agent output. Hallucinations are not eliminated; independent output and task validation remain necessary.

Known risks: long runs/3+ cycles, live repeated-read intervention, semantic recall fidelity, narrow physical margin in the observed workload, constrained Linux/Hermes/llama.cpp integration and external dependencies. Windows/native EXE, broader agents and generic OpenAI-compatible backends are roadmap items. This source is released under [MIT](LICENSE); external dependencies and model weights have separate terms. No push, repository initialisation or tag accompanies this candidate.
